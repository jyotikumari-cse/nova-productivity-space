# ✨ NOVA — Your Personal Productivity Space

NOVA is a modern, interactive productivity website designed to help users organize tasks, manage study goals, save notes, and track personal progress in one place.

## 🚀 Features

* **Smart Dashboard:** View your productivity statistics.
* **Task Manager:** Add, complete, and delete tasks.
* **Study Planner:** Organize and track study tasks.
* **Quick Notes:** Save and manage important notes.
* **Career Tracker:** Set goals and monitor your progress.
* **Progress Chart:** Visualize your productivity.
* **Responsive Design:** Use the website on desktop and mobile screens.
* **Interactive UI:** Enjoy smooth hover animations and a modern interface.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage

## 💡 About the Project

NOVA is my first personal web development project. I built it to practice front-end development and create a useful productivity tool with interactive features.

## 🎯 Project Goal

The goal of NOVA is to make everyday planning easier by bringing tasks, study activities, notes, and career goals together in one place.
